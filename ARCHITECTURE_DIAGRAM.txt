DATA FLOW EXAMPLE: Deposit Event
================================================================================

User deposits 1 WETH on Ethereum:
  
  [Blockchain] TX: call weth9.deposit()
       ↓
  [Ponder] Detects: Deposit event (dst=0x123, wad=1000000000000000000)
       ↓
  [Handler] ponder.on("weth9:Deposit", ...)
       ↓
  [Database] INSERT INTO account (address, balance)
             VALUES (0x123, 1000000000000000000)
             ON CONFLICT (address) DO UPDATE SET balance = balance + 1000000000000000000
       ↓
  [API] Query: { accounts(where: { address: "0x123" }) { balance } }
       ↓
  [Response] { data: { accounts: [{ balance: "1000000000000000000" }] } }


USER ACTION: Same user withdraws 0.5 WETH

  [Blockchain] TX: call weth9.withdraw(500000000000000000)
       ↓
  [Ponder] Detects: Withdrawal event (src=0x123, wad=500000000000000000)
       ↓
  [Handler] ponder.on("weth9:Withdrawal", ...) ❌ NOT IMPLEMENTED
       ↓
  [Database] No update! Balance remains: 1000000000000000000 ❌ WRONG
       ↓
  [Reality] Actual balance: 0.5 WETH
             Indexed balance: 1.0 WETH
       ↓
  [Result] Data inconsistency! ⚠️ BUG


ISSUES BY SEVERITY
================================================================================

CRITICAL (Must fix immediately):
  1. startBlock: "latest" - Misses all historical events
  2. Only Deposit events tracked - Withdrawals/Transfers ignored
  3. No authentication - Public API access
  4. No error handling - Silent failures
  5. No rate limiting - DoS vulnerability

HIGH (Must fix before production):
  6. No logging - Cannot debug issues
  7. SQL endpoint exposed - Injection attack vector
  8. No input validation - Invalid queries accepted
  9. No database indexes - Slow queries
  10. No env validation - Silent configuration failures

MEDIUM (Should fix soon):
  11. Missing CORS - Frontend integration issues
  12. No chainId in schema - Cross-chain confusion
  13. No documentation - Onboarding difficult
  14. SQLite default - Not production-ready
  15. No pre-commit hooks - Code quality issues
